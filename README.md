# Doodle-Jump-website-Game
#PROJECT DESCRIPTION:
This project is a fully functional browser-based version of the popular mobile game “Doodle Jump,” built using HTML5, CSS3, and JavaScript. 
The game features dynamic platform generation, infinite vertical scrolling, power-ups, and score tracking.
Players control a character (the jumper) that ascends by jumping across platforms and collecting boosts, aiming for the highest score possible.
Additionally, the game includes a Firebase-powered leaderboard where players can enter their name and score at the end of a session.
The top scores are retrieved and displayed to promote competition and engagement.

#OBJECTIVES:
1.Recreate Doodle Jump game mechanics using modern web technologies.
2.Ensure responsive gameplay across devices.
3.Implement a real-time leaderboard using Firebase Realtime Database.

#TECHNOLOGIES USED:
FRONTEND:
1.HTML5
2.CSS3
3.Vanilla JavaScript
4.Canvas API
